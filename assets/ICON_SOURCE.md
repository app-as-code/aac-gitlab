# Icon source

The default icon is taken from the homarr-labs dashboard-icons collection. The dark-mode and
light-mode variants come from the selfh.st icon collection (repository `selfhst/icons`),
because the homarr-labs collection has no light/dark variants for GitLab. No icon was drawn
or modified by hand.

| File in this repo | Upstream file | Used for |
|---|---|---|
| `icon.svg` | `svg/gitlab.svg` (repository `homarr-labs/dashboard-icons`) | Default, and fallback in the README |
| `icon-dark.svg` | `svg/gitlab-light.svg` (repository `selfhst/icons`) | White logo for dark mode |
| `icon-light.svg` | `svg/gitlab-dark.svg` (repository `selfhst/icons`) | Dark logo for light mode |

Download URLs:

- https://cdn.jsdelivr.net/gh/homarr-labs/dashboard-icons/svg/gitlab.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/gitlab-light.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/gitlab-dark.svg
